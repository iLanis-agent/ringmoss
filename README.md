# Ringmoss1.0 TEST
Native Java/Canvas Android8+ Tapa-style puzzle. Each fixed white clue lists lengths of separate dark runs around its eight-neighbor ring. Digits are separate lengths, in any order, with at least one white neighbor between runs. The ring wraps around corners; missing off-board neighbors are white. All dark tiles must be edge-connected and cannot form a solid 2x2. Twelve unique boards, undo/reset, saved moss palette/shade marks and GG007 menu/site/privacy.

Independent Java cyclic-neighbor component and BFS oracle exhausts 65,536 masks per board against production circular run scanning and bitset floodfill, confirming unique solutions and no dark 2x2. Bounds/toggle/solve/undo/replay and adapter navigation/settings/privacy/taps/persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime/performance/browser handoff QA incomplete. Not final or Play published.

Registry803 Tapa/cyclic-neighbor-runs scan found no functional match. Unlike Inkgrove row/column runs or Poolmere adjacent component sizes,this counts separate cyclic runs in each clue neighborhood. Known Tapa genre, not global invention.
